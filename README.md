## À propos

Actuellement en troisième année de licence informatique à l’Université de Lille, je présente ici mes travaux universitaires en Java ainsi que des bases open source que j’explore pour le développement web et l’intelligence artificielle.

Ce portfolio distingue les projets auxquels j’ai contribué des templates en cours d’appropriation. Chaque dépôt précise son origine, son état et les vérifications effectuées.
